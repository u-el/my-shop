# 06. 구현 메모 — 루무드(LUMOOD)

> 01~05 문서를 기준으로 만든 첫 구현입니다. 아래 **임시안** 항목은 '추후 결정'을 구현하기 위해 임시로 채운 값이며, 확정 사항이 아닙니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # dist/ 에 정적 파일 생성
```

## 기술

- React + Vite, react-router-dom (`/` 메인, `/experience` 체험, `/product` 상품 정보)
- 이미지 파일 없이 SVG 일러스트로 가상 공간·제품을 표현

## 05 문서 7-3 변경 제안 반영 (03·04 문서와 Figma에는 아직 미반영)

| 번호 | 반영 내용 | 파일 |
|---|---|---|
| ① | 가상 공간 + 조절 패널(C-01~C-03)을 한 화면에 좌우 배치. S-02-01과 S-02-02를 한 화면으로 합침 | `src/pages/Experience.jsx` |
| ② | 프리셋을 색 미리보기 + 이름 + 짧은 설명의 타일로 | `src/pages/Experience.jsx` |
| ③ | 메인 첫 화면을 가로 전체 방 일러스트 + 겹친 제목으로 | `src/pages/Home.jsx` |
| ④ | "일반 천장등과 비교" 스위치 → 좌우 드래그 비교 (새 조절 도구, 04 문서에 ID 필요 — 제안: C-04) | `src/pages/Experience.jsx` |

추가: 체험에서 고른 프리셋·색상·밝기를 상품 정보 페이지까지 유지해 제품 이미지와 구매 섹션에 보여줍니다 ("체험한 분위기 그대로 구매", 01 문서 3).

## 임시안 (모두 `src/data/content.js` 한 곳에서 수정)

| 항목 | 임시안 |
|---|---|
| 가상 공간 표현 방식 | SVG 자취방 일러스트 (창문·침대·협탁 위 무드 조명) |
| 장면 프리셋 | 휴식(앰버 55%) · 집중(달빛 화이트 90%) · 영화(라벤더 25%) · 잠들기 전(캔들 15%) |
| 색상 | 8가지, 차가운 빛 → 따뜻한 빛 순서 |
| 상품 상세 정보 | 크기 · 빛 색상 · 밝기 · 조작 · 전원 (값은 모두 예시) |
| 외부 스토어 | 미정 → 링크 `#`, 누르면 "준비 중" 안내. `STORE.url`에 주소를 넣으면 새 창으로 이동 |
| 문구 | 제목·본문 문구 전부 임시 |
