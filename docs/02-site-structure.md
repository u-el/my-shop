# 02. 사이트 구성 — 루무드(LUMOOD)

> 이 문서는 `01-site-purpose.md`의 방문자 흐름을 기준으로 확정한 페이지 구성입니다.
> **확정** 사항과 **추후 결정** 사항을 구분해 표시했습니다.

---

## 1. 방문자 행동별 구성 (확정)

| 방문자 행동 | 필요한 정보·기능 | 배치할 페이지 / 섹션 | 다음 행동 |
|---|---|---|---|
| SNS 방 사진을 보고 사이트에 들어온다 | 루무드가 무엇인지 알려주는 소개, 따뜻하고 아늑한 첫인상 | 메인 페이지 › 첫 화면 섹션 | 사이트가 해주는 일을 파악한다 |
| "내 방에서도 저런 분위기가 날까?" 궁금해한다 | 구매 전 가상 체험 안내, 체험 시작 버튼 | 메인 페이지 › 체험 안내 섹션 | 체험 페이지로 이동한다 |
| 장면 프리셋으로 분위기를 바꿔 본다 | 가상 공간 (표현 방식 **추후 결정**), 장면 프리셋 (종류·개수 **추후 결정**) | 체험 페이지 › 가상 공간 + 프리셋 영역 | 색상과 밝기를 직접 조절한다 |
| 색상과 밝기를 직접 조절한다 | 색상 조절, 밝기 조절, 가상 공간 분위기 실시간 반영 | 체험 페이지 › 직접 조절 영역 | 상품 정보 페이지로 이동한다 |
| 상품 상세 정보를 확인한다 | 상품 상세 정보 (담을 항목 **추후 결정**) | 상품 정보 페이지 › 상세 정보 섹션 | 구매를 결정한다 |
| 체험한 분위기 그대로 구매를 결정한다 | 외부 스토어 구매 링크 (스토어 종류 **추후 결정**) | 상품 정보 페이지 › 구매 섹션 | 외부 스토어로 이동해 구매한다 |

---

## 2. 페이지별 묶음 (확정)

| 페이지 | 묶은 기능 | 역할 |
|---|---|---|
| 메인 페이지 | 브랜드 소개, 체험 안내, 체험 시작 버튼 | 첫인상을 주고 체험으로 이끈다 |
| 체험 페이지 | 가상 공간, 장면 프리셋, 색상·밝기 직접 조절 | 핵심 행동이 일어나는 곳 |
| 상품 정보 페이지 | 상품 상세 정보, 외부 스토어 구매 링크 | 체험 후 구매 결정을 돕는다 |

---

## 3. 선택한 대안과 이유 (확정)

| 선택 항목 | 고른 대안 | 이유 |
|---|---|---|
| 페이지 구성 | A안: 메인 / 체험 / 상품 정보의 3페이지 | 기능별로 역할이 분명하게 나뉘고, 비슷한 기능끼리 묶어 페이지로 구분하는 기준에 가장 가깝다. |
| 구매 링크 위치 | A안: 상품 정보 페이지에만 배치 | 문서의 방문자 흐름(체험 → 상세 정보 확인 → 구매)을 그대로 따른다. |

---

## 4. 추후 결정

아래 항목은 아직 정하지 않았습니다. 확정 사항이 아닙니다.

- 장면 프리셋의 종류와 개수
- 가상 공간의 표현 방식
- 상품 상세 정보에 담을 항목
- 연결할 외부 스토어의 종류
- 각 페이지 안의 섹션 순서와 화면 구성
