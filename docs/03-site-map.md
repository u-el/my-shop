## 2. 사이트맵 (가로 계층도)

```
LUMOOD 루무드 (스마트 무드 조명 브랜드 사이트)
│
├── [PAGE 01] 메인 페이지 ─ 첫인상을 주고 체험으로 이끈다
│     ├── 첫 화면 섹션 ─ 브랜드 소개 · 따뜻하고 아늑한 첫인상
│     ├── 체험 안내 섹션 ─ 구매 전 가상 체험 안내 · 체험 시작 버튼 → 체험 페이지
│     └┄┄ (추후 결정) 섹션 순서 · 화면 구성
│
├── [PAGE 02] 체험 페이지 ─ 핵심 행동이 일어나는 곳
│     ├── 가상 공간 + 프리셋 영역 ─ 가상 공간 · 장면 프리셋으로 분위기 바꿔 보기
│     │     ├┄┄ (추후 결정) 가상 공간 표현 방식 (실제 방 사진 / 일러스트 등)
│     │     └┄┄ (추후 결정) 장면 프리셋 종류 · 개수
│     ├── 직접 조절 영역 ─ 색상 조절 · 밝기 조절 · 가상 공간 실시간 반영 → 상품 정보 페이지
│     └┄┄ (추후 결정) 섹션 순서 · 화면 구성
│
└── [PAGE 03] 상품 정보 페이지 ─ 체험 후 구매 결정을 돕는다
      ├── 상세 정보 섹션 ─ 무드 조명(단일 제품) 상세 정보
      │     └┄┄ (추후 결정) 상세 정보에 담을 항목
      ├── 구매 섹션 ─ 외부 스토어 구매 링크 (구매 링크는 이 페이지에만 배치)
      │     └┄┄ (추후 결정) 연결할 외부 스토어 종류 → 사이트 밖 외부 스토어로 이동
      └┄┄ (추후 결정) 섹션 순서 · 화면 구성
```

`──` 확정된 연결 · `┄┄` 추후 결정 항목으로 이어지는 연결

## 3. 페이지별 구성 (확정)

| 페이지 | 섹션 | 담는 내용 | 다음 행동 |
|---|---|---|---|
| 메인 페이지 | 첫 화면 섹션 | 루무드 소개, 따뜻하고 아늑한 첫인상 | 사이트가 해주는 일을 파악한다 |
| 메인 페이지 | 체험 안내 섹션 | 구매 전 가상 체험 안내, 체험 시작 버튼 | 체험 페이지로 이동한다 |
| 체험 페이지 | 가상 공간 + 프리셋 영역 | 가상 공간, 장면 프리셋 | 색상과 밝기를 직접 조절한다 |
| 체험 페이지 | 직접 조절 영역 | 색상 조절, 밝기 조절, 가상 공간 실시간 반영 | 상품 정보 페이지로 이동한다 |
| 상품 정보 페이지 | 상세 정보 섹션 | 상품 상세 정보 | 구매를 결정한다 |
| 상품 정보 페이지 | 구매 섹션 | 외부 스토어 구매 링크 | 외부 스토어로 이동해 구매한다 |

**방문자 흐름**

SNS 방 사진으로 유입 → 메인 → 체험(프리셋 · 색상 · 밝기 조절) → 상품 정보 → 외부 스토어에서 구매

## 4. 추후 결정

아래 항목은 아직 정하지 않았습니다. 사이트맵에서 점선 박스로 표시했습니다.

| 항목 | 위치 |
|---|---|
| 가상 공간 표현 방식 (실제 방 사진 / 일러스트 등) | 체험 페이지 › 가상 공간 + 프리셋 영역 |
| 장면 프리셋의 종류와 개수 | 체험 페이지 › 가상 공간 + 프리셋 영역 |
| 상품 상세 정보에 담을 항목 | 상품 정보 페이지 › 상세 정보 섹션 |
| 연결할 외부 스토어의 종류 | 상품 정보 페이지 › 구매 섹션 |
| 각 페이지 안의 섹션 순서와 화면 구성 | 메인 · 체험 · 상품 정보 페이지 전체 |
