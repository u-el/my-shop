### 배치

| 행 | 놓인 것 |

페이지 사이의 파란 화살표는 버튼 동선(B-01, B-02, B-03)입니다.

### 표기 규칙 (Figma 범례와 동일)

| 표기 | 의미 |
|---|---|
| 회색 선 | 텍스트 (진한 굵은 선 = 제목, 옅은 선 = 본문) |
| X 상자 | 이미지 (좌측 상단에 이미지 설명) |
| 주황 굵은 테두리 + `핵심 행동` 태그 | 핵심 행동: 가상 공간에서 색상·밝기를 직접 조절하며 분위기 체험 |
| 파란 태그 | ID — 메뉴 `M` · 페이지 `P` · 섹션 `S` · 조절 `C` · 버튼 `B` |
| 점선 태그 / 점선 상자 | 추후 결정 |

메뉴 이름, 버튼 이름, 조절 도구 이름은 구분을 위해 실제 글자로 적었습니다. 나머지 본문·제목은 회색 선입니다.

## 3. 페이지별 화면 (섹션은 위에서 아래 순서)

### P-01 메인 페이지 — 첫인상을 주고 체험으로 이끈다

```
┌──────────────────────────────────────────────────────────┐
│ LUMOOD [M-01]                    체험하기 [M-02] 상품 정보 [M-03] │
├──────────────────────────────────────────────────────────┤
│ [S-01-01 첫 화면 섹션]                                      │
│  ━━━━━━━━━━ 제목 2줄          ┌──────────────┐            │
│  ───────── 본문 3줄           │ X 따뜻하고 아늑한 │            │
│                               │   방 분위기     │            │
│                               └──────────────┘            │
├──────────────────────────────────────────────────────────┤
│ [S-01-02 체험 안내 섹션]                                    │
│  ┌──────────────┐   ━━━━━━ 제목 1줄                         │
│  │ X 가상 체험    │   ───── 본문 3줄                          │
│  │   미리보기     │   [B-01] (체험 시작하기) → P-02 체험 페이지   │
│  └──────────────┘                                          │
└──────────────────────────────────────────────────────────┘
```

| 섹션 ID | 섹션 | 구성 요소 |
|---|---|---|
| S-01-01 | 첫 화면 섹션 | 제목(회색 선 2줄), 본문(회색 선 3줄), 이미지 X: 따뜻하고 아늑한 방 분위기 |
| S-01-02 | 체험 안내 섹션 | 이미지 X: 가상 체험 미리보기, 제목(1줄), 본문(3줄), 버튼 B-01 체험 시작하기 |

### P-02 체험 페이지 — 핵심 행동이 일어나는 곳

```
┌──────────────────────────────────────────────────────────┐
│ LUMOOD [M-01]                  **체험하기** [M-02] 상품 정보 [M-03] │
├──────────────────────────────────────────────────────────┤
│ [S-02-01 가상 공간 + 프리셋 영역]                            │
│  ━━━━━ 제목 1줄 / ───── 본문 1줄                             │
│  ┌──────────────────────────────────────────────┐         │
│  │ X 가상 공간 (조명 분위기 실시간 반영)                │         │
│  └──────────────────────────────────────────────┘         │
│  ┆추후 결정 · 가상 공간 표현 방식 (실제 방 사진 / 일러스트 등)┆     │
│  ┏━━ 핵심 행동 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓         │
│  ┃ 장면 프리셋 [C-01]                              ┃         │
│  ┃ (●프리셋 1) (프리셋 2) (프리셋 3) (프리셋 4)        ┃         │
│  ┃ ┆추후 결정 · 장면 프리셋 종류 · 개수┆               ┃         │
│  ┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛         │
├──────────────────────────────────────────────────────────┤
│ [S-02-02 직접 조절 영역]                                     │
│  ───── 본문 1줄                                             │
│  ┏━━ 핵심 행동 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓         │
│  ┃ 색상 [C-02]                 밝기 [C-03]          ┃         │
│  ┃ ◉ ○ ○ ○ ○ ○ ○ ○             ━━━━━━━●──── 70%     ┃         │
│  ┃ 조절 즉시 S-02-01 가상 공간에 실시간 반영              ┃         │
│  ┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛         │
│  [B-02] (상품 정보 보기) → P-03 상품 정보 페이지               │
└──────────────────────────────────────────────────────────┘
```

| 섹션 ID | 섹션 | 구성 요소 |
|---|---|---|
| S-02-01 | 가상 공간 + 프리셋 영역 | 제목(1줄), 본문(1줄), 이미지 X: 가상 공간(가로 전체), 추후 결정 태그(가상 공간 표현 방식), **핵심 행동 테두리**: C-01 장면 프리셋 선택(선택 칩 4개, 첫 번째 선택됨) + 추후 결정 태그(종류·개수) |
| S-02-02 | 직접 조절 영역 | 본문(1줄), **핵심 행동 테두리**: C-02 색상 선택(원형 색상 8개, 첫 번째 선택됨) + C-03 밝기 조절(슬라이더, 70%) + "조절 즉시 S-02-01 가상 공간에 실시간 반영" 안내, 버튼 B-02 상품 정보 보기 |

- 프리셋 칩 4개와 색상 8개는 크기와 형태를 보여주기 위한 **예시 개수**입니다. 실제 프리셋 종류·개수는 추후 결정입니다.

### P-03 상품 정보 페이지 — 체험 후 구매 결정을 돕는다

```
┌──────────────────────────────────────────────────────────┐
│ LUMOOD [M-01]                  체험하기 [M-02] **상품 정보** [M-03] │
├──────────────────────────────────────────────────────────┤
│ [S-03-01 상세 정보 섹션]                                     │
│  ┌──────────────┐   ━━━━━ 제목 1줄                          │
│  │ X 무드 조명    │   ───── 본문 3줄                          │
│  │   상품        │   ─── ────────  목록 항목 1                │
│  │              │   ─── ────────  … 목록 항목 5              │
│  └──────────────┘   ┆추후 결정 · 상세 정보에 담을 항목┆         │
├──────────────────────────────────────────────────────────┤
│ [S-03-02 구매 섹션]  (가운데 정렬)                             │
│              ━━━━━ 제목 1줄 / ───── 본문 2줄                 │
│   [B-03] (외부 스토어에서 구매하기) → 외부 스토어 (사이트 밖)      │
│              ┆추후 결정 · 연결할 외부 스토어 종류┆               │
└──────────────────────────────────────────────────────────┘
```

| 섹션 ID | 섹션 | 구성 요소 |
|---|---|---|
| S-03-01 | 상세 정보 섹션 | 이미지 X: 무드 조명 상품, 제목(1줄), 본문(3줄), 상세 정보 목록(항목 5줄, 항목명 + 값), 추후 결정 태그(상세 정보에 담을 항목) |
| S-03-02 | 구매 섹션 | 제목(1줄), 본문(2줄), 버튼 B-03 외부 스토어에서 구매하기, 추후 결정 태그(연결할 외부 스토어 종류) |

- 목록 5줄은 **예시 개수**입니다. 담을 항목은 추후 결정입니다.
- 구매 링크는 이 페이지에만 둡니다 (02 문서 확정 사항).
